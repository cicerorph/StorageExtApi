# StorageExtApi
An Simple API using Hono + MongoDB.

## Installation
Clone the Repo
```bash
git clone https://github.com/cicerorph/StorageExtApi.git
```

Install dependencies:
```bash
cd StorageExtApi
bun install
```

Edit the envinroment variables:
```bash
cp .env.example .env
nano .env
```

To run:
```bash
bun run index.ts
```
